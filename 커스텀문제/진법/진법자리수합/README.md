# 진법 자리수 합

## 문제 설명

자연수 n과 진법 k가 주어질 때,
n을 **k진법**으로 변환했을 때 **각 자리수의 합**을 구하세요.

(단, k진법에서 10 이상의 자리수는 그 숫자 그대로 더한다.
예: 16진법에서 'A'는 10, 'B'는 11로 계산한다.)

---

## 예시

### 입력

n = 45, k = 3

### 출력

3

### 설명

1. 45를 3진법으로 변환: `1200`
2. 자리수 합: `1 + 2 + 0 + 0 = 3`

---

## 예시 2

### 입력

n = 255, k = 16

### 출력

30

### 설명

1. 255를 16진법으로 변환: `ff`
2. 각 자리수: f = 15, f = 15
3. 자리수 합: `15 + 15 = 30`

---

## 예시 3

### 입력

n = 100, k = 2

### 출력

3

### 설명

1. 100을 2진법으로 변환: `1100100`
2. 자리수 합: `1 + 1 + 0 + 0 + 1 + 0 + 0 = 3`

---

## 제한사항

- 1 <= n <= 1,000,000
- 2 <= k <= 16

---

## 핵심 아이디어

1. n을 k진법 문자열로 변환한다. (`n.toString(k)`)
2. 문자열을 한 글자씩 순회하면서 숫자로 변환해 합한다.
3. 'a'~'f' 같은 글자는 `parseInt(글자, 16)` 으로 숫자로 바꿀 수 있다.
   또는 `parseInt(글자, k)`로 해당 진법 기준으로 바로 변환 가능하다.

---

## 학습 포인트

- 진법 변환 (`toString(k)`)
- 문자열 순회
- 알파벳을 포함한 자리수 처리 (`parseInt(char, k)`)
- 다양한 진법에 대한 일반화된 처리
