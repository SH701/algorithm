# 진법 회문 판별

## 문제 설명

자연수 n과 진법 k가 주어질 때,
n을 **k진법**으로 변환한 결과가 **회문(palindrome)** 이면 `true`,
아니면 `false`를 반환하세요.

회문이란 앞에서 읽으나 뒤에서 읽으나 똑같은 문자열을 말합니다.
예: `101`, `12321`, `aba`

---

## 예시

### 입력

n = 9, k = 2

### 출력

true

### 설명

9를 2진법으로 변환: `1001`
앞에서 읽기: `1001`
뒤에서 읽기: `1001`
→ 회문이므로 `true`

---

## 예시 2

### 입력

n = 10, k = 2

### 출력

false

### 설명

10을 2진법으로 변환: `1010`
앞에서 읽기: `1010`
뒤에서 읽기: `0101`
→ 회문이 아니므로 `false`

---

## 예시 3

### 입력

n = 121, k = 10

### 출력

true

### 설명

121을 10진법으로 변환: `121`
앞뒤로 읽어도 `121` → 회문 `true`

---

## 예시 4

### 입력

n = 27, k = 3

### 출력

false

### 설명

27을 3진법으로 변환: `1000`
앞에서 읽기: `1000`
뒤에서 읽기: `0001`
→ 회문이 아니므로 `false`

---

## 제한사항

- 1 <= n <= 1,000,000
- 2 <= k <= 16

---

## 핵심 아이디어

1. n을 k진법 문자열로 변환한다. (`n.toString(k)`)
2. 그 문자열을 뒤집은 결과와 비교한다.
   - `str.split('').reverse().join('')` 으로 뒤집기
3. 원본과 뒤집은 것이 같으면 `true`, 다르면 `false`.

또는 투포인터로 양 끝에서 좁혀가며 비교해도 된다.

---

## 학습 포인트

- 진법 변환 (`toString(k)`)
- 문자열 뒤집기 (`split('').reverse().join('')`)
- 회문 판별
- 투포인터 기법 (선택)
