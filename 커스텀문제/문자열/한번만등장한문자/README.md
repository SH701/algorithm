# 한 번만 등장한 문자 개수

## 문제 설명

소문자 알파벳으로만 이루어진 문자열 s가 주어질 때,
**딱 한 번만 등장한 문자의 개수**를 반환하세요.

---

## 예시

### 입력

"banana"

### 출력

1

### 설명

각 문자의 등장 횟수:
- b: 1 ← 한 번만 등장
- a: 3
- n: 2

한 번만 등장한 문자는 'b' 하나 → 1

---

## 예시 2

### 입력

"apple"

### 출력

3

### 설명

각 문자의 등장 횟수:
- a: 1 ← 한 번
- p: 2
- l: 1 ← 한 번
- e: 1 ← 한 번

한 번만 등장한 문자: a, l, e → 3개

---

## 예시 3

### 입력

"aabbcc"

### 출력

0

### 설명

모든 문자가 2번씩 등장. 한 번만 등장한 문자는 없음 → 0

---

## 예시 4

### 입력

"hello"

### 출력

3

### 설명

- h: 1 ← 한 번
- e: 1 ← 한 번
- l: 2
- o: 1 ← 한 번

한 번만 등장한 문자: h, e, o → 3개

---

## 제한사항

- 1 <= s.length <= 10,000
- s는 소문자 알파벳('a' ~ 'z')으로만 이루어져 있다.

---

## 핵심 아이디어

1. 객체로 각 문자의 등장 횟수를 센다.
   ```js
   obj[s[i]] = (obj[s[i]] || 0) + 1
   ```
2. 객체를 순회하면서 값이 1인 key의 개수를 센다.

---

## 학습 포인트

- 객체를 활용한 빈도수 카운팅
- `for...in` 으로 객체 순회
- 조건에 맞는 항목 카운팅
