# 문자열 압축

## 문제 설명

문자열 s가 주어질 때,
**연속으로 반복되는 문자**를 `문자 + 반복횟수` 형태로 압축한 문자열을 반환하세요.

단, 반복 횟수가 1인 경우는 숫자를 생략합니다.

---

## 예시

### 입력

"aaabbc"

### 출력

"a3b2c"

### 설명

- a가 3번 연속 → `a3`
- b가 2번 연속 → `b2`
- c가 1번 → `c` (1은 생략)

---

## 예시 2

### 입력

"aabbccdd"

### 출력

"a2b2c2d2"

### 설명

- a 2번 → `a2`
- b 2번 → `b2`
- c 2번 → `c2`
- d 2번 → `d2`

---

## 예시 3

### 입력

"abcdef"

### 출력

"abcdef"

### 설명

연속 반복이 없으므로 원본 그대로 반환.

---

## 예시 4

### 입력

"aaaaa"

### 출력

"a5"

### 설명

a가 5번 연속 → `a5`

---

## 예시 5

### 입력

"aabbaabb"

### 출력

"a2b2a2b2"

### 설명

연속된 구간 기준이므로 a2, b2, a2, b2로 압축.

---

## 제한사항

- 1 <= s.length <= 10,000
- s는 소문자 알파벳으로만 이루어져 있다.

---

## 핵심 아이디어

1. 현재 문자(`cur`)와 연속 횟수(`count`)를 변수로 관리한다.
2. 다음 문자가 현재 문자와 같으면 `count++`.
3. 다르면 결과 문자열에 `cur + (count > 1 ? count : '')` 를 붙이고 초기화.
4. 반복문이 끝난 뒤 마지막 문자도 결과에 추가하는 것을 잊지 않는다.

---

## 학습 포인트

- 문자열 순회
- 연속 구간 처리 (현재 값 vs 다음 값 비교)
- 조건부 문자열 조합
- 반복문 종료 후 마지막 처리
