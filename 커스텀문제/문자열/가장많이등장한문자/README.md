# 가장 많이 등장한 문자

## 문제 설명

소문자 알파벳으로만 이루어진 문자열 s가 주어질 때,
**가장 많이 등장한 문자**를 반환하세요.

만약 가장 많이 등장한 문자가 여러 개라면 **알파벳 순으로 가장 앞선 문자**를 반환합니다.

---

## 예시

### 입력

"banana"

### 출력

"a"

### 설명

각 문자의 등장 횟수:
- b: 1
- a: 3
- n: 2

가장 많이 등장한 문자는 'a' (3번)

---

## 예시 2

### 입력

"apple"

### 출력

"p"

### 설명

각 문자의 등장 횟수:
- a: 1
- p: 2
- l: 1
- e: 1

가장 많이 등장한 문자는 'p' (2번)

---

## 예시 3

### 입력

"abcabc"

### 출력

"a"

### 설명

a, b, c가 모두 2번씩 등장.
가장 많이 등장한 문자가 동률이므로 알파벳 순으로 가장 앞선 'a' 반환.

---

## 예시 4

### 입력

"z"

### 출력

"z"

### 설명

문자가 하나뿐이므로 'z' 반환.

---

## 제한사항

- 1 <= s.length <= 10,000
- s는 소문자 알파벳('a' ~ 'z')으로만 이루어져 있다.

---

## 핵심 아이디어

1. 객체(또는 Map)를 사용해 각 문자의 등장 횟수를 센다.
   ```js
   const count = {}
   count[char] = (count[char] || 0) + 1
   ```
2. 객체를 순회하면서 가장 많이 등장한 문자를 찾는다.
3. 동률이라면 알파벳 순으로 더 앞선 문자를 선택한다.
   - 문자열 비교는 `>`, `<` 연산자로 가능 ('a' < 'b')

---

## 학습 포인트

- 객체를 활용한 빈도수 카운팅
- 문자열 순회
- 최댓값 추적 + 동률 처리
- 문자(char) 비교
