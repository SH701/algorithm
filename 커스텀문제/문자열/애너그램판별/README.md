# 애너그램 판별

## 문제 설명

두 문자열 s1, s2가 주어질 때,
두 문자열이 **애너그램(Anagram)** 인지 판별하세요.

애너그램이란 두 문자열이 **같은 문자를 같은 개수만큼 가지고 있지만 순서만 다른 경우**를 말합니다.

같으면 `true`, 다르면 `false`를 반환합니다.

---

## 예시

### 입력

s1 = "listen", s2 = "silent"

### 출력

true

### 설명

"listen" → l:1, i:1, s:1, t:1, e:1, n:1
"silent" → s:1, i:1, l:1, e:1, n:1, t:1

같은 문자를 같은 개수만큼 가지므로 애너그램 → `true`

---

## 예시 2

### 입력

s1 = "hello", s2 = "world"

### 출력

false

### 설명

"hello" → h:1, e:1, l:2, o:1
"world" → w:1, o:1, r:1, l:1, d:1

문자 구성이 다르므로 애너그램이 아님 → `false`

---

## 예시 3

### 입력

s1 = "abc", s2 = "abcd"

### 출력

false

### 설명

길이가 다르므로 애너그램이 아님 → `false`

---

## 예시 4

### 입력

s1 = "aabbcc", s2 = "abcabc"

### 출력

true

### 설명

둘 다 a:2, b:2, c:2 → 애너그램 → `true`

---

## 제한사항

- 1 <= s1.length, s2.length <= 10,000
- s1, s2는 소문자 알파벳('a' ~ 'z')으로만 이루어져 있다.

---

## 핵심 아이디어

**방법 1: 객체로 빈도수 비교**
1. 두 문자열의 길이가 다르면 바로 `false`.
2. s1의 각 문자 빈도수를 객체에 담는다.
3. s2를 순회하면서 객체의 값을 1씩 감소시킨다.
4. 도중에 값이 음수가 되거나 없는 키가 나오면 `false`.
5. 끝까지 통과하면 `true`.

**방법 2: 정렬해서 비교 (간단)**
1. 두 문자열을 각각 정렬한다.
2. 정렬된 결과가 같으면 `true`.
   ```js
   s1.split('').sort().join('') === s2.split('').sort().join('')
   ```

---

## 학습 포인트

- 객체를 활용한 빈도수 비교
- 문자열 길이 비교
- 문자열 정렬 (`split('').sort().join('')`)
- 두 자료구조의 동등성 판별
