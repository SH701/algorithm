# 소수 자리수 합

## 문제 설명

정수 n이 주어질 때,
1부터 n까지의 소수들의 각 자리수 합을 모두 더한 값을 구하세요.

---

## 예시

### 입력

10

### 출력

17

### 설명

10 이하의 소수:
2, 3, 5, 7

자리수 합:
2 + 3 + 5 + 7 = 17

---

## 예시 2

### 입력

20

### 출력

41

### 설명

20 이하의 소수:
2, 3, 5, 7, 11, 13, 17, 19

자리수 합:
2+3+5+7+1+1+1+3+1+7+1+9 = 41

---

## 제한사항

- 1 <= n <= 100000

---

## 핵심 아이디어

1. 에라토스테네스의 체로 소수를 판별한다.
2. 소수를 문자열로 변환한다.
3. 각 자리수를 더한다.

---

## 학습 포인트

- 소수 판별
- 에라토스테네스의 체
- 문자열 변환
- 자리수 합 구하기
