# 골드바흐 파티션

## 문제 설명

짝수 n이 주어질 때,
n을 **두 소수의 합**으로 나타내는 방법의 수를 구하세요.

순서가 다르더라도 같은 쌍은 한 번만 센다.
즉, (3, 7)과 (7, 3)은 같은 쌍으로 본다.

---

## 예시

### 입력

10

### 출력

2

### 설명

10을 두 소수의 합으로 나타내는 방법:
- 3 + 7 = 10
- 5 + 5 = 10

총 2가지

---

## 예시 2

### 입력

20

### 출력

2

### 설명

20을 두 소수의 합으로 나타내는 방법:
- 3 + 17 = 20
- 7 + 13 = 20

총 2가지

---

## 예시 3

### 입력

100

### 출력

6

### 설명

100을 두 소수의 합으로 나타내는 방법:
- 3 + 97
- 11 + 89
- 17 + 83
- 29 + 71
- 41 + 59
- 47 + 53

총 6가지

---

## 제한사항

- 4 <= n <= 100000
- n은 항상 짝수

---

## 핵심 아이디어

1. 에라토스테네스의 체로 n 이하의 소수를 판별한다.
2. 2부터 n/2까지 순회하면서 i와 n-i가 모두 소수인지 확인한다.
3. 둘 다 소수인 경우의 수를 센다.

---

## 학습 포인트

- 소수 판별
- 에라토스테네스의 체
- 두 수의 합 조건 탐색
- 중복 제거 (i <= n-i 조건)
